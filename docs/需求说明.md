# URDF 碰撞体简化编辑器需求说明

## 编辑与拟合

- 加载完整 URDF，显示 visual、原始 collision 和编辑后的 collision；支持按 link 单独查看。
- 每个 link 可管理多个 sphere、box、cylinder、capsule 或 convex 碰撞体，支持添加、复制、删除、替换、撤销和重做。
- “拟合并添加”支持自由方向和部件轴对齐。部件轴对齐必须在所属 link 局部坐标系中处理源几何：box 沿局部 XYZ 对齐；cylinder 与 capsule 可选局部 X、Y 或 Z 为中心轴。
- 用户可删除当前 link 的全部原始 collision，同时保留新增图形；该操作只影响工作副本和导出结果，可撤销，也可用“恢复当前部件原始碰撞体”恢复。

## 单位与参数操作

- 距离控件默认使用毫米（mm），角度控件默认使用度（°）；内部、URDF 与 YAML 使用米和弧度。
- 半径和长度提供绝对数值框与绝对值滑条。用户可按毫米设置各自滑条的最大范围；系统按最大值生成约一千个刻度，兼顾细调与足够的调整范围。绝对数值框不限制可输入的有效尺寸范围。
- 修改参数或拖动位姿后，三维预览立即更新，工作副本在短暂防抖后写入。

## 文件行为

- 源 URDF 和源网格不可覆盖；自动修改仅写入独立工作区。
- 正式保存输出 URDF、YAML 和引用资源；支持兼容胶囊（三个基本体）和原生 URDF 1.1 capsule。
- 参数 YAML 可独立导入导出。重新打开带匹配 `collisions.yaml` 的输出 URDF 时，恢复逻辑胶囊、凸包和轴对齐信息。

## 界面与源码编辑

- 界面采用 Robot Viewer 风格的紧凑蓝色卡片和圆角控件，整体支持浅色太阳模式与柔和蓝灰色月亮模式切换；暗色模式不得使用纯黑背景。切换即时应用到控制区、独立窗口和源码编辑区。圆角样式不得裁切工作区标题、折叠栏标题或控件文字。
- 选中碰撞体时显示其局部坐标系：X 轴为纯红 `(255, 0, 0)`、Y 轴为纯绿 `(0, 255, 0)`、Z 轴为纯蓝 `(0, 0, 255)`，并随该碰撞体的局部位姿更新。
- 主工具栏常驻提供“打开 URDF 源码编辑器”开关。源码编辑器是可移动、可关闭的独立窗口，编辑区本身支持 XML 语法高亮，并能刷新、校验并应用当前工作副本 XML。应用时验证 XML、`robot` 根节点和唯一 link 名称，随后创建新的工作副本重新加载；不会覆盖初始 URDF 或销毁之前会话。
- 主工具栏常驻提供“打开关节角度调整”开关。窗口列出全部可动关节，提供以度为单位的滑条、精确输入、归零及关闭按钮；调整只改变三维预览姿态，不写入 URDF 关节定义或碰撞体局部位姿。
- 碰撞体自身的自由旋转使用独立的可移动窗口操作，提供 X/Roll、Y/Pitch、Z/Yaw 三个角度滑条和精确输入、归零及关闭按钮；数值始终以度显示和编辑。部件轴对齐或球体等旋转锁定时，窗口明确禁用旋转控件。
- 删除正视、后视、左视、右视、俯视、仰视和等轴测按钮，保留聚焦当前部件与聚焦整机操作。
- “打开模型”面板默认展开。命令行带 `--urdf` 时启动后直接加载该文件；未带该参数时由用户在展开的面板中手动加载。
