# URDF 碰撞体简化编辑器技术方案与需求说明

## 1. 产品目标与范围

本项目是一个 Python 驱动、在本机浏览器运行的中文 URDF 碰撞体简化编辑器。它面向需要把复杂 mesh collision 转换为基础碰撞体或凸包的机器人开发人员，完整流程为：

> 加载整机 URDF → 选择 link → 拟合或添加碰撞体 → 调整尺寸与局部位姿 → 自动同步工作副本 → 撤销、保存或导出参数。

第一版只处理已经展开的 `.urdf` 文件，不直接编辑 Xacro；不包含动力学仿真、自动多体分解和 ROS 运行时依赖。编辑器绝不覆盖输入 URDF、输入网格或纹理。

## 2. 技术架构

| 层级 | 技术 | 职责 |
| --- | --- | --- |
| 运行与打包 | Python 3.11+、uv、Hatchling | 环境、依赖和命令行入口 |
| 浏览器界面与三维视图 | Viser | 三维网格显示、场景交互、中文 GUI、浮动窗口 |
| URDF 与运动学 | yourdfpy、lxml | 解析 link/joint、关节预览、定向 XML 更新 |
| 几何处理 | trimesh、pycollada、NumPy、SciPy | STL/OBJ/DAE 加载、凸包、包围体、坐标变换与旋转 |
| 状态与参数 | Pydantic、PyYAML | 编辑状态校验、YAML 导入导出 |
| XML 源码高亮 | Pygments | XML 可编辑高亮显示 |
| 质量保障 | pytest、Ruff | 回归测试和静态检查 |

核心模块如下：

- `RobotDocument`：保存原始 XML、资源路径、网格缓存、link 与关节运动学。
- `CollisionShape`：稳定 ID、所属 link、类型、尺寸、局部 `xyz/rpy`、轴对齐模式与轴向。
- `EditorState`：当前碰撞体、已编辑 link 和显示状态。
- `EditorSession`：独立工作区、自动同步、命令历史、撤销与重做。
- `UrdfWriter`：生成工作 URDF、正式输出、凸包资源与胶囊兼容输出。
- `ParameterIO`：YAML 参数校验、导入、导出与匹配报告。
- `EditorApp`：Viser 界面、三维显示、拟合后台任务和浮动工具窗口。

## 3. URDF 加载与三维显示

### 3.1 加载

- 加载完整机器人及 STL、OBJ、DAE 网格。
- 支持相对路径、绝对路径、`file://` 和 `package://`；自动在 URDF 附近与补充包目录中发现 `package.xml`。
- 应用 mesh scale、visual/collision origin 和关节变换。
- 单个网格缺失时给出具体 link 与路径提示，其他部件仍可查看。
- 命令行提供 `--urdf`、`--package-dir`、`--recover`、`--workspace`、`--host`、`--port`。

启动规则：

- 带 `--urdf` 启动时直接加载指定模型。
- 未带 `--urdf` 时，“打开模型”面板默认展开，用户手动填写路径并加载。

### 3.2 场景交互

- 支持 link 搜索、选择、隐藏、仅显示当前部件、恢复全部部件、聚焦当前部件和聚焦整机。
- visual、原始 collision、编辑后 collision 分别控制显示与透明度。
- 可动关节可在独立窗口中以度为单位预览；不修改 URDF joint 定义，也不改变碰撞体局部位姿。
- 选中碰撞体时显示其局部坐标系：X 为纯红 `(255, 0, 0)`，Y 为纯绿 `(0, 255, 0)`，Z 为纯蓝 `(0, 0, 255)`。
- 不提供正视、后视、左视、右视、俯视、仰视或等轴测按钮，减少重复视图控制。

## 4. 碰撞体模型与拟合

每个 link 可含多个碰撞体，支持添加、复制、重命名、删除、替换当前 link、删除源 collision、恢复源 collision、撤销和重做。

| 类型 | 可编辑参数 | 初拟合 |
| --- | --- | --- |
| `sphere` | 半径、中心 | 包围球 |
| `box` | XYZ 完整边长、位置、旋转 | 有向包围盒 |
| `cylinder` | 半径、直段长度、位置、旋转 | 包围圆柱 |
| `capsule` | 半径、直段长度、位置、旋转 | 主轴胶囊 |
| `convex` | 位置、旋转、重新生成 | 单个凸包 mesh |

- 默认从原始 collision 拟合；不存在时使用 visual，用户可切换来源。
- 拟合前统一将源网格转换到 link 局部坐标，包含源 origin 与 scale。
- 初拟合以覆盖源顶点为要求，不承诺最小体积；退化网格给出中文错误。
- 凸包由生成 mesh 表示，不能手动添加，且不支持部件轴对齐。
- 胶囊自身中心轴固定为局部 Z；总长度等于直段长度加两倍半径。直段为零时等效为球体。

### 4.1 自由拟合与部件轴对齐

“新形状对齐”可选“自由”或“部件轴”。部件轴对齐始终相对于所属 link，而不是世界坐标，因此关节运动不会破坏其对齐关系。

| 类型 | 部件轴对齐行为 |
| --- | --- |
| box | link 局部 XYZ 轴对齐包围盒，局部旋转为零 |
| cylinder | 用户选择 X/Y/Z 中心轴，默认 Z；自身 Z 映射至选定 link 轴 |
| capsule | 用户选择 X/Y/Z 中心轴，默认 Z；自身 Z 映射至选定 link 轴 |
| sphere | 无方向区别，仅调整中心与半径 |
| convex | 不支持，保持凸包生成与自由位姿 |

- 切换到部件轴会基于当前拟合来源重新拟合，作为一次可撤销操作。
- 轴对齐模式允许平移和尺寸编辑，锁定旋转；解除后保留当前几何并恢复自由旋转。
- “拟合并添加”在选择部件轴时必须以 link 局部坐标系拟合。

## 5. 单位、参数与位姿

- 界面默认使用毫米（mm）和度（°）；距离可切换为米（m）。URDF 与 YAML 始终存米与弧度。
- 位姿均相对于所属 link。`xyz` 是局部平移，`rpy` 是局部旋转。
- 半径与长度支持精确数值输入，以及绝对值滑条。用户可分别设定滑条最大范围，系统生成约一千个刻度以兼顾细调和大范围调整；不再使用倍率滑条。
- 三维拖动器用于平移和自由旋转；部件轴对齐与球体关闭旋转拖动。
- 碰撞体自由旋转使用独立浮动窗口，包含 X/Roll、Y/Pitch、Z/Yaw 的度数输入、滑条、归零和关闭；旋转被锁定时窗口控件禁用。

## 6. 工作副本、撤销与保存

### 6.1 自动同步和恢复

- 打开 URDF 后建立独立 `.collision-editor/<session>` 工作目录，包含源快照、`working.urdf`、`state.json`、参数文件和生成网格。
- 参数有效变更后立即刷新场景，并在约 300 ms 防抖后写入工作副本；连续拖动只形成一条撤销记录。
- 使用临时文件和原子替换，落盘失败保留内存状态并显示未同步原因。
- 支持撤销、重做、恢复当前 link 原始碰撞体和重启后恢复工作区；撤销栈仅在当前会话中保存。

### 6.2 保存和导出

- “保存”和“另存为”只允许写至新输出目录，不可覆盖源 URDF 或源资源。
- 输出包含 URDF、`collisions.yaml` 与必要 `assets/`，资源路径按输出目录组织。
- 参数 YAML 按 link 分组，记录版本、源文件指纹、单位、逻辑胶囊、凸包资源、轴对齐模式、轴向、尺寸和位姿。
- 导入 YAML 按 link 名匹配，显示错误或缺失资源，并整体作为一次可撤销操作应用。

胶囊导出模式：

1. **兼容模式（默认）**：一个 cylinder 加两个 sphere，球心为胶囊局部轴的 `±直段长度/2`。
2. **原生模式**：写 `<capsule>` 并使用 URDF 1.1；下游解析器需支持该标签。

## 7. URDF 源码编辑器

主工具栏提供“打开 URDF 源码编辑器”。窗口可移动、可关闭，包含：

- XML 语法高亮的可编辑代码区；
- “刷新为当前工作副本”；
- “校验并应用源码”；
- “关闭源码编辑器”。

应用源码时校验 XML 语法、`robot` 根节点以及唯一且有效的 link 名称。校验成功后，内容写入新的会话工作区并重新加载。原始输入文件与原会话工作区均保留，因此可恢复到修改前状态。

## 8. 界面与主题规范

- 采用参考 Robot Viewer 的紧凑操作布局、蓝色强调色、圆角卡片、圆角控件与独立工具窗口。
- 圆角不能裁切工作区标题、折叠栏标题或控件文本。
- 顶部提供太阳/月亮主题切换：浅色模式为默认；暗色模式使用柔和蓝灰色，而不是纯黑，且覆盖主控制区、浮动窗口和 XML 编辑区。
- 顶部常驻入口包括主题切换、URDF 源码编辑器和关节角度调整。

## 9. 验收标准

- RXL-6F-C3 示例能完整加载 9 个 link，`package://` 资源可解析，部件可单独显示。
- 同一 link 能添加多个类型；修改后的视图、YAML 与 URDF 一致。
- 非零关节预览姿态下，碰撞体仍保持正确 link 局部位姿。
- 轴对齐 box 的边平行 link 轴；cylinder/capsule 沿 X/Y/Z 正确生成、旋转锁定与解除锁定可撤销。
- 多源网格、mesh scale、origin 和退化网格处理正确，错误提示为中文。
- 删除原始 collision、恢复、撤销、重做和重新加载输出保持一致。
- 两种胶囊输出位置、尺寸、轴向一致；兼容输出可由传统 URDF 读取器加载。
- YAML 往返保留几何与轴对齐数据；源文件哈希及非目标 XML 语义保持不变。
- 缺失资源、非法数值、XML 非法和写入失败均给出明确反馈。
- 普通参数编辑以本地示例为准在约 100 ms 内反馈；耗时拟合在后台执行。

## 10. 质量要求

- 使用 Ruff 进行静态检查。
- 使用 pytest 覆盖几何拟合、持久化、工作区恢复、XML 校验与编辑会话核心行为。
- 每次功能变更至少执行 `ruff check`、Python 编译检查和完整 pytest 回归。
